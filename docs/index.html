กำลังหาตำแหน่ง…

อนุญาตตำแหน่งเมื่อเบราว์เซอร์ถาม

แตะหน้าปัดเพื่อสแกนลายนิ้วมือ

ลงทะเบียนลายนิ้วมือ

ทำครั้งเดียวต่อเครื่อง ลายนิ้วมืออยู่ในเครื่องของคุณเท่านั้น ระบบไม่เก็บภาพลายนิ้วมือ

ลงทะเบียนเครื่องนี้แล้ว

วิธีใช้

  1. ลงทะเบียนเครื่องนี้ครั้งเดียว ด้วยรหัสพนักงานและรหัสลงทะเบียนจากแอดมิน
  2. แตะหน้าปัด แล้ววางนิ้วบนเซ็นเซอร์ หรือทำตามหน้าจอ
  3. ระบบบันทึกเวลาและตำแหน่งให้เอง ครั้งแรกคือเข้างาน ครั้งถัดไปคือออกงาน

ตรวจสอบเครื่อง

    ใช้เหมือนแอปได้ เปิดลิงก์นี้ใน Chrome แล้วเลือก “เพิ่มไปที่หน้าจอหลัก” (iPhone: Safari > แชร์ > เพิ่มไปยังหน้าจอโฮม)
    เพิ่งบันทึกไปเมื่อครู่ จึงไม่บันทึกซ้ำ
